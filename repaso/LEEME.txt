REPASO - CLASE 1 (Backend con Python)
=====================================

Cada archivo de esta carpeta corresponde al archivo del mismo nombre en
clase1/ y tiene cuatro partes:

  CONCEPTOS   la teoría del tema, resumida
  NOTAS       errores encontrados en la versión de clase y por qué
  CÓDIGO      la versión mejorada, comentada línea por línea
  PRACTICAR   ejercicios para resolver solos

Se ejecutan desde esta carpeta con:   python nombre_del_archivo.py
(Probados con Python 3.14; funcionan desde Python 3.8.)

Errores principales que se corrigen
-----------------------------------
3_2  Con 18 años pedía autorización (<= en vez de <) y con 59 cobraba
     precio de jubilado.
4_2  while True sin break: preguntaba la edad para siempre.
5_3  // en el promedio (9.5 se mostraba como 9) y ZeroDivisionError si
     no se cargaba ninguna nota.
6_2  "defecto" aparecía como producto en la carta; f-string con comillas
     dobles anidadas (SyntaxError antes de Python 3.12).
7    calcular_iva devolvía "Hola" o un número según el caso.
8_1  pedir_pizza() rompía con 1 pizza (UnboundLocalError); valor + valor
     en vez de valor + valor2.
8_2  cuenta_regresiva(-10) nunca llegaba al caso base (RecursionError).
10   cumpleanios() recalculaba es_mayor con la edad vieja.
